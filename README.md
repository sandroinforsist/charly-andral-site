# Charly Andral Osbourne — Portfolio Site

Mockup interativo do site portfolio do artista visual Charly Andral Osbourne. Este protótipo serve como guia visual para a construção final no Framer.

## Estrutura do projeto

```
charly-andral-site/
├── index.html              ← Mockup principal (single-page com navegação JS)
├── README.md
├── .gitignore
└── assets/
    └── img/
        ├── home/           ← 5 imagens do slideshow da Home
        ├── sugarcane/      ← 17 colagens digitais (Cuts through a Sugarcane Archipelago)
        ├── selva/          ← 8 fotos da instalação (A selva que nos escapa)
        ├── rewilding/      ← 2 colagens digitais (Rewilding)
        ├── olhos/          ← 46 fotos da intervenção (Olhos nos Olhos)
        └── ubris/          ← 27 fotos das festas performáticas (Ubris)
```

## Especificações técnicas

- **Tipografia:** Cormorant Garamond (títulos) + Inter (corpo)
- **Paleta:** `#0a0a0a` (fundo), `#e8e8e8` (texto), `#c8b88a` (accent)
- **Imagens:** JPEG otimizadas, max 1600px largura, qualidade 82
- **Plataforma final:** Framer
- **Idioma do conteúdo:** Inglês

## Como usar

Abra `index.html` em qualquer navegador. A navegação entre páginas é feita via JavaScript (single-page).
